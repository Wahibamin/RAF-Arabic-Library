# رف | RAF — المكتبة العربية الرقمية

**مشروع Python/Django لتطوير مكتبة إلكترونية عربية بنظام اشتراكات**

**تطوير:** وهيب الكبودي | Wahib Al-Kaboudi  
**المنصة:** Web / Python  
**التقنيات:** Python · Django · SQL/SQLite · HTML · Bootstrap RTL · Linux · Git

## نبذة عن المشروع

رف مشروع تطبيقي ضمن مسار Python وهندسة البرمجيات وقواعد البيانات وLinux. يقدّم مكتبة عربية رقمية باستخدام Django تتضمن إدارة الحسابات والكتب والاشتراكات والقراءة.

## الوظائف والمكونات الأساسية

- نظام حسابات ومصادقة للمستخدمين.
- فهرس كتب ومؤلفين وتصنيفات مع البحث والتصفية.
- طلبات الاشتراك ورفع إيصالات الدفع ومراجعتها.
- قراءة ملفات PDF مع فحص صلاحية الاشتراك على الخادم.
- المفضلة وحفظ تقدم القراءة واستئنافها.
- تهيئة التشغيل والنشر على Linux مع سجلات اختبار ووثائق نشر.

## التقنيات المستخدمة

Python · Django · SQL/SQLite · HTML · Bootstrap RTL · Linux · Git

## التشغيل محليًا

```bash
python -m venv .venv
# فعّل البيئة الافتراضية بالطريقة المناسبة لنظام التشغيل
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

ملفات إعداد البيئة موثقة في `docs/DEPLOYMENT.md`. استخدم قيمًا خاصة بك للمتغيرات البيئية ولا ترفع أسرار الخادم أو قواعد بيانات المستخدمين.

## حالة المشروع وحدوده

النسخة التجريبية تستخدم SQLite واستضافة محدودة الموارد. رفع المواد المحمية ومسارات الوسائط يتطلب إعدادًا آمنًا؛ لا يتضمن المستودع بيانات الإنتاج أو ملفات الدفع الحقيقية.
